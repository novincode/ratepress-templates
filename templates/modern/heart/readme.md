# Modern Heart Template

A beautiful animated heart template with glassmorphism effects and smooth particle animations.

## Features

- ✨ Smooth heartbeat animation on activation
- 🎨 Glassmorphism design (backdrop blur)
- 💫 Particle burst effect
- 🌓 Dark mode support
- 📱 Mobile responsive
- ♿ Fully accessible (ARIA labels, keyboard navigation)
- 🌍 RTL support

## Category

**Binary** - Simple like/unlike functionality

## Compatibility

- RatePress: 1.0.0+
- WordPress: 5.0+
- Modern browsers (Chrome, Firefox, Safari, Edge)

## Usage

This template is automatically loaded when selected from the RatePress Templates marketplace. No additional configuration required.

### Data Flow

1. User clicks heart button
2. JavaScript submits rating via RatePress API
3. Server updates rating count
4. UI updates with new count and animation

### Customization

You can override styles by targeting these classes:

```css
.ratepress-template.modern-heart { }
.modern-heart__button { }
.modern-heart__icon { }
.modern-heart__count { }
```
